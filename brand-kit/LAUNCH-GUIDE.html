Step 2. Make the 5 accounts 60 min

For each app, open the matching file in 4-captions (for example TikTok.txt). It has the exact username, name, bio and link to copy and paste.

  1. TikTok: sign up, then go to Settings → Account → switch to a Business account and pick the category Education. Add the photo, name, bio and website link.
  2. Instagram: sign up, then switch to a Professional account (Creator or Business). Add the photo, bio and link.
  3. Facebook Page: from your own Facebook, choose "Create a Page" called LEXIS. Add the photo and facebook-cover.png. Connect it to the Instagram account when Facebook asks.
  4. YouTube: create a channel called LEXIS. Add the photo and youtube-banner.png.
  5. LINE Official Account: go to manager.line.biz and create a free account. Add the photo and line-cover.png.
Tip: use the same username everywhere if you can (learnwithlexis). If it's taken, use learnwithlexis.th.

Step 5. Turn on "Continue with Google" 15 min

This lets people sign up in one tap instead of typing an email and password.

  1. Go to console.cloud.google.com and create a project called LEXIS.
  2. Open APIs & Services → OAuth consent screen. Choose External, set the app name to LEXIS, add your email, and save.
  3. Open Credentials → Create credentials → OAuth client ID → Web application.
  4. Under Authorized redirect URIs, paste:
    https://ucgoqgwopnxiktlxlyhc.supabase.co/auth/v1/callback
  5. Press Create, then copy the Client ID and Client secret.
  6. Go to supabase.com, open the LEXIS project, then Authentication → Sign In / Providers → Google. Switch it on, paste both values and save.
  7. Message me "Google done". I'll make the button appear on the website.
